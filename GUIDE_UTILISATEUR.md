# 📖 Guide Utilisateur — Site du Collège Privé la Vision Future

**À destination de :** Visiteurs, Parents d'élèves, Candidats, Élèves  
**Version :** 1.0 — Mai 2026

---

## 🏠 Présentation du site

Le site du **Collège Privé la Vision Future** vous permet de :

- Découvrir l'établissement, son histoire et sa vision
- Consulter les programmes scolaires par cycle
- Déposer une demande d'admission en ligne
- Envoyer un message à l'équipe
- Suivre l'état de votre demande en temps réel
- Consulter les offres d'emploi disponibles
- Télécharger les emplois du temps par classe

---

## 🗺️ Navigation sur le site

Le menu en haut de chaque page donne accès aux rubriques suivantes :

| Rubrique | Ce que vous y trouvez |

---

## 📝 Envoyer un message de contact

1. Cliquez sur **"Contact"** dans le menu
2. Remplissez le formulaire :
   - Votre nom et prénom
   - Votre adresse e-mail
   - L'objet de votre message
   - Le contenu de votre message
3. Cliquez sur **"Envoyer"**

✅ Vous recevrez un **numéro de référence** du format `CONT-2026-XXXX`.  
Conservez ce numéro pour suivre votre demande.

---

## 🎓 Faire une demande d'admission

1. Cliquez sur **"Admissions"** dans le menu
2. Consultez les informations sur les tarifs et le processus
3. Cliquez sur **"Déposer une demande d'admission"**
4. Remplissez le formulaire :
   - Informations sur l'élève (nom, prénom, date de naissance)
   - Niveau souhaité (6e, 5e, 4e, 3e, 2nde, 1ère, Terminale)
   - Informations du parent / tuteur
   - Documents requis si demandés
5. Cliquez sur **"Soumettre la demande"**

✅ Vous recevrez un **numéro de référence** du format `ADM-2026-XXXX`.  
Conservez ce numéro pour suivre votre dossier.

---

## 🔍 Suivre l'état de votre demande

Que ce soit pour un message de contact ou une demande d'admission, vous pouvez suivre l'avancement de votre dossier à tout moment.

### Comment accéder au suivi

1. Depuis le menu ou le pied de page, cliquez sur **"Suivre ma demande"**
   — ou accédez directement à l'adresse : `https://votre-site.com/suivi`
2. Saisissez votre numéro de référence (ex. : `CONT-2026-1234` ou `ADM-2026-5678`)
3. Cliquez sur **"Rechercher"**

### Les statuts possibles

| Statut | Signification |
|--------|---------------|
| 🔴 **Nouveau** | Votre demande a bien été reçue, elle n'a pas encore été traitée |
| 🟡 **En cours d'examen** | Un membre de l'équipe examine votre dossier |
| 🟠 **Entretien programmé** | Un rendez-vous vous sera communiqué sous peu (admissions) |
| 🟢 **Traité / Accepté** | Votre demande a été finalisée |
| ⚫ **Archivé** | Votre demande a été classée |

> **Astuce :** La page de suivi affiche également l'historique complet des changements de statut de votre demande.

---

## 💼 Consulter les offres d'emploi

1. Cliquez sur **"Carrières"** dans le menu
2. Parcourez la liste des offres publiées
3. Cliquez sur une offre pour voir les détails
4. Téléchargez le document PDF d'appel d'offre
5. Cliquez sur **"Candidater à cette offre"** pour soumettre votre candidature

### Soumettre une candidature

1. Remplissez le formulaire de candidature :
   - Vos informations personnelles
   - Votre lettre de motivation
   - Votre CV (fichier PDF ou Word)
2. Cliquez sur **"Envoyer ma candidature"**

---

## 📅 Télécharger un emploi du temps

1. Cliquez sur **"Emplois du Temps"** dans le menu  
   *(accessible depuis la rubrique Programmes ou Contact)*
2. Sélectionnez votre classe dans la liste
3. Cliquez sur **"Voir / Télécharger le PDF"**

## ❓ Questions fréquentes

**Q : Comment obtenir un numéro de référence ?**  
R : Il est automatiquement généré après l'envoi de votre formulaire (contact ou admission). Si vous ne l'avez pas reçu, vérifiez vos spams ou renvoyez le formulaire.

**Q : Combien de temps pour traiter ma demande d'admission ?**  
R : Les dossiers sont traités dans un délai de 3 à 7 jours ouvrables. Vous pouvez suivre l'avancement via la page Suivi.

**Q : Puis-je modifier ma demande après envoi ?**  
R : Non. Si vous avez fait une erreur, envoyez un nouveau message via le formulaire de contact en indiquant votre numéro de référence.

**Q : Le site fonctionne-t-il sur mobile ?**  
R : Oui, le site est entièrement adapté aux smartphones, tablettes et ordinateurs.

**Q : Mes données sont-elles protégées ?**  
R : Oui. Vos informations sont traitées conformément à notre politique de confidentialité, accessible en bas de chaque page.
